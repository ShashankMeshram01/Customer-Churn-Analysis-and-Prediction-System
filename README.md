## ✨ Features
- 📊 Live analytics dashboard with 4 KPI metric cards
- 🤖 Real-time ML churn prediction with probability score
- 📈 4 comprehensive visual analysis charts
- 🗄️ MySQL database with 7,043 customer records
- 🌐 Fully deployed Flask web application

## 🤖 Model Performance
| Model | Accuracy |
|---|---|
| Logistic Regression | **80.38%** ✅ |
| Gradient Boosting | 79.53% |
| Random Forest | 78.68% |

## 📊 Key Findings
- Month-to-month customers churn at **42.7%**
- Electronic cheque users churn at **45.3%**
- Senior citizens churn at **41.7%**
